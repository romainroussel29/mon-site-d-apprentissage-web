Cours suivi

Concepts clés

Partie 1 - Découvrez le web et ses origines

Web

Systeme de documents connectés sur internet

Internet

Réseau informatique mondial

Cloud

Réseau mondial de serveurs distants qui stockent et traitent des données

W3C

Organisme de standardisation du web

Partie 2 - Distinguez les langages du Web

Langages client

Langages exécutés dans le navigateur

Navigateurs

Programmes informatiques qui permettent d'accéder à internet

Langages serveur

Langages exécutés sur un serveur web

Frameworks

Ensemble de règles et de bibliothèques pour développer des applications

Bases de données

Système de stockage et de gestion de données

Site responsive

Site web qui s'adapte automatiquement à la taille de l'écran

Application mobile

Application conçue pour être utilisée sur un appareil mobile

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Ordinateurs puissants conçus pour fournir des ressources, des services et des fonctionnalités à d’autres ordinateurs, équipements ou clients au sein d’un réseau

Adresse IP

Identifiant unique attribué à chaque appareil connecté à un réseau

Nom d’hôte et DNS

Nom donné à un serveur pour faciliter son identification sur le réseau

Protocoles

Ensemble normalisé de règles définissant le formatage et le traitement des données

Partie 4 - Identifiez les métiers du web

Développeurs

Professionnels chargés de concevoir, développer et maintenir les applications web

Product Managers et chefs de projets

Professionnels responsables de la gestion et de la direction des projets de développement web

Designers

Professionnels chargés de concevoir l'interface utilisateur et l'expérience utilisateur d'une application web

Testeurs

Professionnels chargés de vérifier la qualité et les performances d'une application web

Techniciens informatique

Professionnels chargés de maintenir et de gérer les systèmes informatiques et les réseaux

Langages de développement web

HTML

Front-End

Squelette du site Web. Il définit la structure de base du contenu, comme les titres, les paragraphes, les images, etc.

CSS

Front-End

Le CSS permet de contrôler l'apparence et la mise en page des éléments d'une page web, séparant ainsi le contenu (HTML) de sa présentation (CSS)

JavaScript

Front-End

Le JavaScript permet d'ajouter de l'interactivité et de la dynamique à une page web, en permettant le contrôle des éléments HTML et la gestion des événements

JavaScript

Back-End

Le JavaScript peut également être utilisé côté serveur pour développer des applications web dynamiques et interactives

PHP

Back-End

Le PHP est un langage de programmation serveur utilisé pour développer des applications web dynamiques

Java

Back-End

Le Java est un langage de programmation orienté objet utilisé pour développer des applications web et mobiles

Python

Back-End

Le Python est un langage de programmation polyvalent utilisé pour le développement web, l'analyse de données et l'intelligence artificielle

C#

Back-End

Le C# est un langage de programmation orienté objet utilisé pour développer des applications web et desktop

SQL

Bases de données

Le SQL est un langage de programmation utilisé pour gérer et manipuler les bases de données relationnelles

Boîte à outils du développeur

  • IDE comme VS Code : L'IDE (Integrated Development Environment) est un logiciel de création d'applications
  • Github : Plateforme basée sur le cloud où vous pouvez stocker, partager et travailler avec d'autres pour écrire du code
  • Librairies / bibliothèques : Ensemble de fonctions, de classes ou de modules pré-écrits et réutilisables qui peuvent être intégrés dans un programme pour effectuer des tâches spécifiques
  • Frameworks : Boîte à outil qui permet de créer des applications web et mobile (Ex : React de JavaScript, Angular de TypeScript, Django de Python)
